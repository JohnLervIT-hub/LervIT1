Required types:
- ID
- DRIVER_LICENSE
- VEHICLE_REGISTRATION
- VEHICLE_PHOTOS
- INSURANCE
- BACKGROUND_CHECK
- PAYOUT_SETUP

Implementation:

1. Add a helper function on the backend, e.g.:
   - `isDriverVerificationComplete(driverId)` → returns true/false plus optional explanation.

2. Integrate this check into:
   - The endpoint or socket that toggles driver status to "Online".

3. On the front end:
   - When the driver taps “Go Online”, call that endpoint.
   - If it returns VERIFICATION_INCOMPLETE, show a modal/banner:
     - “You can’t go online yet. Please complete your Verification Checklist.”
