## Scope of Authorship

The following system expressions documented herein represent original creative and technical work:

1. **System Architecture** — The design and organization of the monorepo structure, API layer, shared type system, and integration architecture.

2. **Workflow Design** — The end-to-end user flows for customers, movers, and administrators, including the multi-step booking process, mover onboarding wizard, and admin management workflows.

3. **State Machine** — The 10-state booking lifecycle with defined transitions, validation rules, active trip protection logic, and terminal state handling.

4. **Decision Orchestration** — The PrecisionMatch dynamic pricing calculator, vehicle class configuration, 3-layer Vision Engine AI pipeline, ground-truth furniture database, proximity matching algorithm, and single-tier vehicle upgrade compatibility system.

5. **Payment Architecture** — The Stripe Connect integration with destination charges, automatic 85/15 platform fee splitting, mover earnings tracking, batch payout processing, and progressive onboarding reminder system.

6. **Data Model** — The PostgreSQL schema comprising 20+ interrelated tables with optimized indexes, covering users, movers, bookings, payments, AI intelligence, support, learning metrics, notifications, and abandoned booking recovery.

7. **API Surface** — The RESTful API design with 70+ endpoints organized by domain, featuring session-based authentication, role-based authorization, Zod validation, and webhook signature verification.

8. **User Experience Design** — The mobile-first, role-based interface design including real-time GPS tracking with custom vehicle icons, progressive booking flow with draft preservation, AI-powered photo analysis integration, dark mode support, and PWA capabilities.
